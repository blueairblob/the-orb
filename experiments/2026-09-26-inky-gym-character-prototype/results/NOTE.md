# Note on the transcripts in this folder

These are the raw evidence transcripts for the character/canon work, cited from the
findings in `../README.md`. All are recovered from the gym's git history at the point
of the move (2026-09-26).

## One file was lost in the move — `2026-09-25-fixation-ab.txt`

`2026-09-25-fixation-ab.txt` (the fixation A/B run cited under the canon findings) was
an **untracked** file in the gym. During the move it was deleted from the gym before it
had been copied here (a copy command aborted early on a filename collision), and being
untracked it was in no git history and no backup — so the **raw transcript is
unrecoverable**.

What is preserved instead, under `fixation-ab-salvage/`, is the experiment's method and
inputs, recovered from the generating session's scratchpad:

- `fixation_ab.sh` — the generator: the user's own 8 questions, a ledger seeded with 10
  real "atmosphere-heavy" facts, run across four conditions (C1 committed code+sheet;
  C2 fixed code + old sheet, `INKY_CANON_ALL=0`; C3 fixed code + new sheet, ALL=0;
  C4 fixed code + new sheet, ALL=60), scoring each reply RECITE (parrots a seeded
  atmosphere fact) vs DODGE (deflects a personal question).
- `seed-real.json` — the seed ledger of the 10 facts.
- `old-sheet.json` — the character sheet variant used.
- `ab-C1-1.json` … `ab-C3-1.json` — the per-condition ledgers as they stood **after**
  the runs (the facts the model actually saved), i.e. partial output evidence.

The transcript could be regenerated by re-running `fixation_ab.sh`, but the output would
be new (the model is non-deterministic) and the run targets gemma on the **live Hermes
fallback** (`:8080`) with a heavy multi-condition load — so it should not be re-run
casually. Treat the salvage as documentation of what the experiment was, not as the
original result.
